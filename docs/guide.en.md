# Feidudu user guide

[中文](guide.zh.md) · [Showcase](index.html)

Import [spritesheet.png](downloads/spritesheet.png) with the Pets skill. The v2 atlas includes nine native states and sixteen gaze directions. Alternatively extract the [installation ZIP](downloads/feidudu-strawhat-mac.zip) into `~/.codex/pets/`, refresh Pets in Codex settings and select the pet.

The [showcase](index.html) contains 11 GIFs, frame storyboards and a compilation MP4. Celebration (a draft) and sleep are website extras; neither is connected to native task events. The client controls when native states and gaze poses are displayed.

To publish, upload the project contents to the repository root and select Settings → Pages → Deploy from a branch → your default branch → `/ (root)`.

See [web preview guide](preview.en.md) for local viewing, interactions and Pages deployment.
